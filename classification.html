Классификация информационных систем

Информационные системы классифицируют по различным признакам: масштаб, назначение, структура, степень автоматизации.

Основные классификационные признаки

  • По функциональности: производственные, финансовые, маркетинговые, кадровые.
  • По уровню управления: операционный, тактический, стратегический.
  • По степени открытости: замкнутые, открытые (с возможностью интеграции).

Примеры ИС по отраслям

Розничная торговля: ERP-системы, кассовые решения, WMS.
Здравоохранение: МИС (медицинские информ. системы), телемедицина.
Логистика: TMS, системы мониторинга транспорта.
Госсектор: Электронное правительство, порталы госуслуг.
