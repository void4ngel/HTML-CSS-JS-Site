# Информационные системы — учебный сайт

Учебный многостраничный веб-сайт, созданный в рамках курса «Проектирование информационных систем».  
Цель проекта — наглядно представить теоретический материал об информационных системах и продемонстрировать навыки вёрстки, стилизации и программирования на JavaScript.

## 🔗 Страницы сайта

| Страница | Файл | Содержание |
|----------|------|-------------|
| Главная | `index.html` | Введение в ИС, виды, преимущества, графическая схема, кнопка с доп. информацией |
| Классификация | `classification.html` | Таблица классификации ИС, списки признаков, блоки по отраслям |
| Компоненты | `components.html` | Аппаратное и программное обеспечение, данные; вставка видео и аудио |
| Интерактив | `form.html` | Форма для расчёта индекса производительности ИС с пользовательскими параметрами |
| О разработчике | `about.html` | Информация об авторе, контакты, ссылки |

## 🛠 Используемые технологии

- **HTML5** — семантическая разметка
- **CSS3** — адаптивный дизайн, флексбоксы, гриды, анимации
- **JavaScript** — расчёты по формуле, управление отображением блоков, обработка событий форм
- **Мультимедиа** — встроенное видео, аудио (файлы `.mp4`, `.mp3` – ожидаются локально)
